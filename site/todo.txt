(These aren't in any particular order)

The general approach for levels of user is
- Public - contest results and simple lists from those results.  Basic data, no interpretation.  Remember that any SQL in these pages will be executed by all bots
- Member - same as public, plus ability to add results, and to add comments.  Any SQL in these pages is protected from bots so can be heavier
- Pro - adds access to interpretation and aggregation of data we hold.
- Superuser - Someone who can see the feedback list and has the access to edit the data to fix them
- Admin - Site owners
